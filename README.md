 Projeto de Análise com Python

Este repositório contém dois notebooks Jupyter com propósitos distintos, voltados para aprendizado e experimentação com dados, Python e bibliotecas como pandas.

📁 Conteúdo

1. jogo_do_bicho.ipynb
   
[JOGO DO BICHO](jogo_do_bicho-2.ipynb)

Este notebook explora o Jogo do Bicho, uma loteria informal popular no Brasil. As funcionalidades incluem:

Mapeamento entre números e grupos de animais.
Leitura de resultados históricos de apostas (arquivo CSV).
Análise visual e estatística dos resultados.
Funcionalidades:

Criação de dicionários para conversão entre números e animais.
Leitura de dados com pandas.
Preparação para análises mais profundas (como agrupamentos ou frequência de animais).
Como usar:

Certifique-se de ter o arquivo resultados_numeros_data.csv na mesma pasta do notebook.

2. estudoPandas.ipynb

[ESTUDO PANDAS](estudoPandas.ipynb)

Notebook focado no uso de pandas. 
Series para manipulação e visualização de dados.

Funcionalidades:

Criação de uma Series aleatória com letras como índice.
Demonstrações com loc, iloc, filtros e gráficos.
Links de documentação oficial para aprofundamento.
